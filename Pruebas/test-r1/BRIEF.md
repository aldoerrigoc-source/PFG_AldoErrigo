# Exercise R1 — Vinyl Catalog

You are given a working web application that displays a catalog of vinyl records: cover, title, artist, and price, in a table.

## What you need to add

At the end of the catalog table, add a summary row that shows:

- The **total** of all record prices.
- The **average** price across all records.

This row must be visually distinguished from the rest of the table rows (for example, with a different background color or bold text).

You don't need to change any other behavior of the application.
