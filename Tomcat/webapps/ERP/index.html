Available Functions

  • Stock List View current product inventory: name, category, quantity, unit cost and image for each product. Use the Edit link on each row to update its stock quantity.
  • Stock Movements Record incoming and outgoing stock movements (entrada/salida). Updates the product's stock quantity and logs the movement.
  • Physical Inventory Count Compare system quantities against physical counts and log discrepancies.
  • User Management Manage user accounts and roles (Administrator only). (Coming soon)
